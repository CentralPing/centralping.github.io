## Installation

```bash
npm install @centralping/ergo-wire
```

## Purpose

`@centralping/ergo-wire` is the canonical wire contract between Ergo server packages and
`@centralping/ergo-fetch`. It provides symmetric parse/format helpers for headers and query
keys so clients and servers stay aligned without duplicating RFC grammars.

## Ergo Stack Wire Profile v1

| Concern | Wire format | Key exports |
| ------- | ----------- | ----------- |
| Idempotency-Key | RFC 8941 sf-string | `formatIdempotencyKey`, `parseIdempotencyKey`, `assertSfStringInner` |
| Link | RFC 8288 | `formatLinkHeader`, `parseLinkHeader`, `paginationLinks`, `cursorPaginationLinks` |
| Offset pagination | `page`, `per_page` query keys | `serializeOffsetParams`, `parseOffsetParams` |
| Cursor pagination | `cursor`, `limit` query keys | `parseCursorParams` |
| Retry-After | seconds or IMF-fixdate | `parseRetryAfter`, `formatRetryAfter` |
| Body fingerprint | SHA-256 hex (Web Crypto) | `fingerprint` |

Ergonomic client options may use `perPage`; serialization always emits `per_page` on the wire.

## Consumers

| Package | Relationship |
| ------- | ------------ |
| `@centralping/ergo` | Re-exports wire primitives from `lib/` (non-breaking shims) |
| `@centralping/ergo-router` | Inherits wire behavior through ergo middleware |
| `@centralping/ergo-fetch` | Runtime dependency for client-side parse/format |
| `@centralping/json-api-query` | Imports `JSON_API_PAGE_STRATEGY_GROUPS` for schema alignment |
