Parses the `Cookie` request header into an [RFC 6265](https://www.rfc-editor.org/rfc/rfc6265)-compliant cookie jar.
The jar uses dual storage: incoming cookies are accessible as own
properties; outgoing cookies are managed via `set()` and serialized by
`toHeader()` into `Set-Cookie` headers.

**Pipeline stage:** Negotiation

## Import

```js
import {cookie} from '@centralping/ergo';
```

## Options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `options` | `object` | — | Forwarded to the [RFC 6265](https://www.rfc-editor.org/rfc/rfc6265) parser (e.g., `{max: 50}` for cookie count limit) |

## Return Value

Returns a cookie jar stored on the [domain accumulator](/concepts/accumulator/)
at `acc.cookies`:

```js
acc.cookies.session    // "abc123" (incoming cookie, own property)
acc.cookies.set(name, value, directives)  // queue outgoing cookie
acc.cookies.toHeader() // ["session=abc123; HttpOnly; Secure", ...]
```

### Jar Methods

| Method | Description |
| ------ | ----------- |
| `set(name, value, directives)` | Queue an outgoing cookie with optional directives |
| `get(name)` | Get an outgoing cookie object |
| `clear(name)` | Clear an outgoing cookie |
| `toHeader()` | Serialize all outgoing cookies to `Set-Cookie` header values |

### Security

- Cookie values are validated against [RFC 6265](https://www.rfc-editor.org/rfc/rfc6265) `cookie-octet` grammar
- Cookie names must be valid HTTP tokens ([RFC 7230](https://www.rfc-editor.org/rfc/rfc7230))
- Domain values are validated against the subdomain grammar ([RFC 1034](https://www.rfc-editor.org/rfc/rfc1034)/[RFC 1123](https://www.rfc-editor.org/rfc/rfc1123))
- Path values are validated against the `path-value` production (any character except CTLs or semicolons)
- SameSite values must be `Strict`, `Lax`, or `None` (case-insensitive, per [RFC 6265bis](https://httpwg.org/http-extensions/draft-ietf-httpbis-rfc6265bis.html))
- Names that collide with jar methods are silently dropped
- Null-prototype parsing prevents prototype pollution

None.

## Usage

<Tabs>
  <TabItem label="Standalone">
    ```js
    import {compose, cookie} from '@centralping/ergo';

    const pipeline = compose(
      cookie(),
      (req, res, acc) => {
        const session = acc.cookies.session;
        acc.cookies.set('visited', 'true', {
          httpOnly: true,
          sameSite: 'Strict',
        });
        return {response: {body: {session}}};
      },
    );
    ```
  </TabItem>
  <TabItem label="ergo-router">

    ```js
    router.get('/dashboard', {
      cookie: {},
      execute: (req, res, acc) => ({
        response: {body: {session: acc.cookies.session}},
      }),
    });
    ```
